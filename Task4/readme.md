# Data Visualization on Dataset for Data Analytics

## Project Description

This project focuses on Data Visualization using the cleaned dataset for Data Analytics. Various graphical representations were created to analyze sales trends, customer behavior, product performance, payment preferences, referral sources, and relationships among variables. The visualizations help transform raw data into meaningful insights and support data-driven decision-making.

## Objectives

- Analyze sales trends and customer behavior.
- Evaluate product performance and revenue contribution.
- Identify patterns and relationships in the data.
- Detect outliers through visual analysis.
- Communicate insights effectively through charts and graphs.

## Dataset Information

| Property | Details |
|----------|----------|
| Dataset Name | Cleaned Dataset for Data Analytics |
| Format | Excel (.xlsx) |
| Domain | Data Analytics |
| Purpose | Data Visualization |

## Data Visualization Tasks Performed

### Data Loading
- Imported the cleaned dataset using Pandas.

### Order Status Distribution
- Visualized the frequency of different order statuses.
- Identified the most common order status.

### Payment Method Usage
- Analyzed the usage frequency of payment methods.
- Identified the most preferred payment method.

### Top Selling Products
- Compared product sales quantities.
- Identified the best-selling products.

### Revenue by Product
- Analyzed revenue generated by each product.
- Identified products contributing the highest revenue.

### Monthly Sales Trend
- Examined monthly revenue patterns.
- Identified trends and fluctuations in sales.

### Referral Source Analysis
- Analyzed customer referral sources.
- Identified channels contributing the highest number of orders.

### Coupon Code Usage
- Visualized coupon code utilization.
- Compared the popularity of different coupon codes.

### Quantity vs Total Price Analysis
- Examined the relationship between quantity purchased and total price.
- Identified patterns and possible correlations.

### Correlation Heatmap
- Analyzed relationships among numerical variables.
- Identified strong positive and negative correlations.

### Total Price Distribution (Box Plot)
- Detected potential outliers in total price.
- Examined the distribution of transaction values.

## Key Insights

- Order status analysis revealed the distribution of completed, pending, and cancelled orders.
- Customer payment preferences were identified through payment method analysis.
- A small number of products contributed significantly to overall sales volume.
- Revenue generation varied across products, with some products contributing more to total revenue than others.
- Monthly sales analysis highlighted fluctuations in revenue over different periods.
- Referral source analysis showed which channels attracted the highest number of customers.
- Coupon usage patterns indicated differences in promotional code adoption among customers.
- Quantity purchased showed a positive relationship with total transaction value.
- Correlation analysis revealed relationships among important numerical variables.
- Box plot analysis detected outliers in transaction values, indicating unusually high or low purchases.

## Results

The visualization analysis successfully revealed:

- Order status distribution patterns
- Customer payment preferences
- Product sales performance
- Revenue contribution by products
- Monthly sales trends
- Referral source effectiveness
- Coupon code usage patterns
- Relationship between quantity and total price
- Correlations among numerical variables
- Presence of outliers in transaction values

## Challenges Faced

- Selecting suitable visualization techniques for different types of data.
- Managing categorical and numerical variables simultaneously.
- Interpreting trends and correlations accurately.
- Extracting meaningful insights from visual representations.
- Identifying and analyzing outliers effectively.

## Conclusion

This Data Visualization project successfully transformed raw data into meaningful graphical representations. Various charts and plots helped uncover sales trends, customer preferences, product performance, correlations, and outliers within the dataset. The insights obtained from the visualizations can support reporting, business analysis, and data-driven decision-making.
